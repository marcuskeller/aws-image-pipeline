Arquitetura do Sistema

Conheça os serviços AWS que fazem essa mágica acontecer.

AWS Lambda

Serverless Functions | Producer

Gera URLs pré-assinadas para que o navegador faça upload seguro diretamente para o S3.

🪣

Amazon S3

Simple Storage Service | Storage & Hosting

Armazena as imagens originais e processadas, hospeda o frontend estático e dispara eventos para o SQS ao receber novos arquivos.

✉️

Amazon SQS

Simple Queue Service | Messaging Queue

Recebe notificações de novos arquivos do S3 e os mantém em fila para o processamento.

☁️

Amazon EC2

Elastic Compute Cloud | Consumer (Worker)

Instância Linux que processa as imagens, redimensionando-as e aplicando as regras de negócio.

📧

Amazon SES

Simple Email Service | Notification

Envia um e-mail automático para o usuário com o link da imagem pronta para download.
